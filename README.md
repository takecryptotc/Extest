# Coinlook Global V3
Responsive static frontend for GitHub Pages.

Files:
- index.html
- styles.css
- app.js
- assets/

Run locally: open index.html, or use `python -m http.server 8080`.
GitHub Pages: deploy `main` branch from `/(root)`.

Production note: never place API secrets or private keys in frontend JavaScript. Real trading, balances, KYC, deposits and withdrawals require a secure backend.
