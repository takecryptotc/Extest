# Coinlook Global V5

Mobile-first responsive crypto exchange frontend prototype.

## Included
- Original Coinlook logo asset (unchanged pixels)
- Responsive Desktop Home
- Mobile-first Home
- Mobile Markets matching the supplied structural reference
- Spot trading with side-by-side mobile order form + order book
- Futures trading screen
- Earn screen
- Assets with Spot / Futures / Earn tabs
- Profile, modals, search/filter/favorites and navigation interactions
- Fixed centered mobile Trade navigation button

## Run locally
python -m http.server 8080
Then open http://127.0.0.1:8080

## GitHub Pages
Upload/push the files in this folder to the repository root so index.html is at the root.

Note: prices/balances are demo UI data. Real trading, authentication, KYC, deposit/withdrawal and balances require secure backend APIs.
